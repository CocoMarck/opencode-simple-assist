# OpenCode Simple Assist

Utiliza a OpenCode como base, y principal dependencia.

Envía prompts/texto a OpenCode. A teclado o por voz. Obtiene la respuesta de OpenCode/Modelo-AI, y normaliza la respuesta MD, a texto legible para el TTS (espeak-ng).

Mantiene sesión/memoria (al dia).

---
# Test
Creamos el entorno virtual de python, y lo activamos:
```bash
./venv.sh
source .venv/bin/activate
```

Ejecutamos:
```bash
python3 main.py
```
